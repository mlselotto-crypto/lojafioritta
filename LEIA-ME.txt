FIORITTA V2 — PRÉVIA DE TESTES, NÃO USAR PARA VENDAS
1. Extraia o ZIP. No computador, acesse https://app.netlify.com/drop após entrar na conta. Arraste somente a pasta public para o Drop. Abra a URL HTTPS gerada no Safari. O nome fioritta pode não estar disponível; escolha outro no painel.
2. Teste busca, filtros, coleções, personalização, sacola, cadastro fictício e checkout com retirada. Não há cobrança, conta autenticada, histórico remoto ou frete real. O WhatsApp abre uma mensagem de orçamento demonstrativo para o número informado; não envie pedidos de teste sem desejar.
3. Para editar: abra /admin.html na URL de teste. Exporte catalog-data.js, substitua public/catalog-data.js e publique novamente na mesma página de deploy. O JSON é apenas referência da estrutura original, não é lido pela loja. O editor não é protegido nem altera dados do servidor.
4. Próxima fase: usar Supabase Auth (email confirmado, recuperação de senha) e banco Postgres com RLS, papéis de administrador verificados no servidor, catálogo público separado de clientes e custos. Integrar Sheets somente no servidor. Não guardar senha no navegador nem expor chave service_role.
5. Mercado Pago Checkout Pro: criar aplicação no painel de desenvolvedores, credenciais de teste em variáveis de ambiente Netlify Functions, criar preferência no servidor com preço recalculado, frete validado e usuário autenticado; registrar pedido, verificar webhook e pagamento na API antes de marcar pago. Não ativar produção antes dos testes e preços aprovados. Parcelamento pendente; confirmar habilitação de conta CPF e modalidades diretamente no Mercado Pago.
6. Fretes: cadastrar dimensões/pesos embalados, configurar tokens privados das duas plataformas, cotar no servidor e validar opção selecionada antes do pagamento. Retirada agendada sem frete. Nunca colocar tokens ou CEP de origem em arquivos públicos.
7. Para próxima etapa com funções, usar repositório privado conectado ao Netlify ou Netlify CLI; Drop de public é apenas a vitrine estática. O projeto não inclui funções reais nesta versão. Antes de vender, validar estoque, preços, imagens, prazos, regras de privacidade/LGPD, identificação do fornecedor, cancelamento e atendimento.
